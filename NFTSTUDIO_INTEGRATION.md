# NFTStudio integration record

Checked against the public service at `https://nftstudio.bodhix.io`, the supplied NFTStudio V5 Solidity contracts and live Shido state on 2026-08-18.

## Verified public behavior

- The live creator route is `https://nftstudio.bodhix.io/deploy`.
- The creator describes a wallet-owned ERC-721 flow with artwork and metadata pinned to IPFS.
- The creation flow explicitly requires wallet connection and a wallet-authenticated session.
- Marketplace collection pages are exposed under `/collections` and individual token URLs are generated by NFTStudio after indexing.

## Supplied contract finding

`BodhiXNFTStudioCollection721V5.sol` supports fixed public/allowlist pricing and an owner-only creator mint. It does not expose an EIP-712 signed-voucher redemption path, per-player promotional pricing, campaign nonces, or the redemption controls Sketch Arena needs. Changing only the existing deployer would not add those capabilities to already deployed collection bytecode.

`BodhixNFTVaultMarketplaceV2.sol` does not need to change for this product model. A new Sketch Arena collection can be approved through its existing collection-approval function and then appear through the normal marketplace/indexing boundary.

## Agreed collection model

- Permanent collection: **Sketch Arena: The Panic Archive**.
- Seasons live inside the collection rather than deploying one collection per Battle Pass. Season 0 is **The First Mess**.
- Sketch Arena deploys one dedicated voucher-capable ERC-721 collection contract after review; it does not deploy a collection for every drawing.
- The backend signs narrowly scoped mint vouchers containing recipient, artwork/metadata commitment, price or free-mint allowance, expiry, nonce, season and campaign context.
- Each nonce is redeemable once. Revocation, pause, allow/deny policy, supply/campaign limits, fee withdrawal and signer rotation are explicit contract controls.
- Players interact with a wallet only when they choose to mint. The current commercial target is the first mint free via Mint Credit, then approximately **$0.99 USD plus gas**, with Battle Pass, achievement and promotional drops able to waive the product fee.
- Sketch Arena never holds player wallet keys and never represents an acknowledged off-chain reward as an on-chain mint.

The first contract implementation draft now lives at `contracts/SketchArenaPanicArchive.sol`. It compiles locally with Solidity 0.8.26 and OpenZeppelin 4.9.6, with optimized deployed bytecode below the EIP-170 size ceiling. This is implementation evidence, not an audit or deployment approval; the required adversarial test matrix is tracked in `PANIC_ARCHIVE_CONTRACT.md`.

## Implemented behind the production gate

- five-minute, single-use wallet ownership challenges;
- durable wallet bindings and mint lifecycle records;
- canonical server-side SVG rendering plus direct pinning to NFTStudio's private Kubo-style API;
- public-safe Season 0 metadata;
- immutable metadata links to the stable public collection route, while token-specific Archive/marketplace links are derived only after the confirmed mint event supplies a token ID;
- one-unit Mint Credit reservation and idempotent consumption only after confirmation;
- capped, expiring, hashed promotion codes plus one-use or multi-use percentage discount entitlements resolved into the voucher price;
- exact EIP-712 voucher signing and encoded `redeem` transaction requests;
- Shido receipt, sender, contract, confirmation depth and `PanicArchiveMinted` event verification;
- resumable pending state and human wallet/RPC/storage/revert errors in the Vault.
- cancellable confirmation polling, immediate duplicate-submission locks and a fresh-voucher retry path after an on-chain revert;
- persistent verified wallet reuse, so a matching connected wallet does not repeat the gasless proof signature for every trophy;
- a full-size afterparty trophy handoff that saves only the original drawer’s round before opening the authenticated Vault;
- a confirmed-only public Panic Archive storefront that never exposes wallet bindings, private player credentials, drafts or pending transactions.

## Safe shipping boundary

Sketch Arena keeps canonical editable artwork in its authenticated Vault. The live deployment now exposes minting only through complete server configuration, receipt verification and the approved/indexed collection. It does not fabricate a mint, claim success before confirmation, or hold player wallet keys. Independent contract review remains an explicit residual risk rather than being misrepresented as complete.
